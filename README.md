# UptimeLogger — downloads

This repository hosts the released binaries of UptimeLogger and nothing else. It is
public because release assets have to be downloadable without an account, and because
the winget manifest points at them.

**Website: <https://uptimelogger.bartels.ug/>** — what it does, how to install it, and
the changelog.

**Downloads: [Releases](https://github.com/roughneck/uptime-logger/releases)** — each
release lists the SHA256 sum of every artefact in its notes.
