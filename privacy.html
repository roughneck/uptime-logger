The application

UptimeLogger runs entirely on your own machine. It has no user account, no backend and no analytics. Everything it records — connection events, settings, the log file — is stored in a local database on your device and is never transmitted anywhere.

The application makes two kinds of outbound requests:

  • Connection probes. TCP connections to the servers configured in the settings (by default public DNS resolvers), used solely to determine whether your internet connection is up. They carry no data about you or about the application.
  • Version check. If left switched on, the application requests a small static file from this website to find out whether a newer version exists. The request contains no identifier, no usage data and no information about your installation; as with any web request, the hosting provider sees your IP address (see below). The check can be switched off in the settings.
